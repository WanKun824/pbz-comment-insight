0流水线

每个阶段都是一条可独立运行的命令，产物落盘，可从任意阶段续跑。

  1. 0pbz rebuild从缓存重建rpid 16.3%→100%，楼中楼关联 0→100%
  2. 1pbz probe关键词探针量化主题分布，为体系定档
  3. 2pbz diag坍缩诊断定位主因：标签文本劫持 ≫ 位置偏置
  4. 3pbz weak规则弱监督高精度优先，允许弃权
  5. 3bpbz dataset封顶+切分按 rpid 切分；内容与上下文重叠另需检查
  6. 4pbz train微调parallel option layout
  7. 5pbz evaluate冻结 test 评测三方对照 + 覆盖率曲线
  8. 6pbz predict全量打标两级推理，valid 闸门
  9. 7pbz aggregate舆情报告主题×情感 / 时间线 / 可行动清单

!已知限制

这一节比上面所有数字都重要。

  • 高test 标签来自规则弱监督，不是人工标注

    分数衡量「模型是否学会了规则体现的那套判别」，不等于人工一致率。抽检估计规则本身 topic_l1 精度约 72–75%；模型的人工一致率仍需独立验证。data/train/golden_todo.xlsx（589 条）需先排除训练重叠，再标注评测。

  • 高二级主题尚无独立评测

    当前弱标签训练集只有一级主题等 12 个维度，没有 topic_l2 监督。中文名称转换不会提升或重新测量模型准确率。

  • 高is_toxic 完全失败

    macro-F1 0.489 = 全预测 B。训练集正例仅 11 条。不可用于自动封禁或处罚。

  • 高sentiment 学不出 neutral

    规则从不输出中立，全量预测里 neutral 仅 0.3%。这是弱监督的结构性缺陷，必须人工补。

  • 中温度拟合撞上限

    温度 5.0 撞 [0.5,5.0] 上限，模型过置信；is_mixed / is_spoiler 的 ECE 偏高（0.118 / 0.106）。

  • 中is_sarcasm, is_actionable 未训练

    规则不可靠、无弱标签，输出是噪声。

  • 中parallel 布局的代价

    需 transformers≥5，只能 eager 后端 —— ONNX 导出、TileLang 快路径、compile=True 都会拒绝。

  • 低IP属地 全为「未知」

    地域维度做不了。

  • 低跨游戏泛化未验证

    词表与二级主题围绕《影之刃零》与这 7 个视频长出来的。
