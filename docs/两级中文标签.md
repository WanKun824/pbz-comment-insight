# 两级中文主题标签

本项目的主题标签由 **8 个一级主题、67 个二级主题**组成。预测文件、概率字典、业务报告、可行动清单和 HTML 看板统一使用中文主题名称。

名称的唯一来源是 [`taxonomy/labels_v2.json`](../taxonomy/labels_v2.json) 中的 `meta.cn_names.topic_l1` 与 `meta.cn_names.topic_l2`。二级名称按一级分支维护，不能脱离所属一级主题单独解释。

## 输出格式

新生成的 `artifacts/pred/pred_full.parquet` 保持字段名稳定：

| 字段 | 内容 | 示例 |
|---|---|---|
| `p_topic_l1` | 中文一级主题 | `技术性能` |
| `p_topic_l2` | 中文二级主题，未执行二级推理时为空 | `着色器编译` |
| `c_topic_l1` / `c_topic_l2` | 原始预测置信度 | 汉化过程不修改 |
| `probs_json.topic_l1` | 概率字典，键为中文一级主题 | `{"技术性能": 0.8, "战斗": 0.2}` |
| `probs_json.topic_l2` | 当前分支的概率字典，键为中文二级主题 | `{"着色器编译": 0.6, "帧率与流畅度": 0.4}` |

`valid` 判为碎片或垃圾时不执行二级推理；`--no-pass2` 也会保留空二级值。其他正交维度的取值约定保持原样。本次汉化只改名称，不重新预测，也不改变置信度或概率。

## 迁移已有英文预测

迁移只依赖 pandas、pyarrow 与配置加载，不需要加载 Laya、下载基座或使用 GPU。

```bash
# 默认原子替换配置中的预测文件
pbz localize-topics

# 保留原文件并另存
pbz localize-topics --pred artifacts/pred/pred_full.parquet --out artifacts/pred/pred_full_中文.parquet

# 使用转换后的文件生成报告
pbz aggregate --pred artifacts/pred/pred_full_中文.parquet

# 看板读取 config.yaml 中 paths.pred 指向的文件
pbz dashboard
```

迁移支持英文、中文和混合数据，重复执行结果相同。空值保持为空；未知扩展标签原样保留，方便发现词表版本差异。报告与看板也能直接读取旧英文预测，并在展示时转换。

`pbz aggregate` 额外生成 `artifacts/report/二级主题分布.csv`，仅含一级主题、二级主题和条数。过滤规则与报告一致；设置 `--min-conf` 后，该表也只统计通过一级主题置信阈值的样本。可行动清单中的两级列名为 `一级主题`、`二级主题`，其内容含评论原文，仅在本地保留。

## 与现有模型兼容

训练数据、模型分支路由和题目的选项顺序继续使用内部兼容标识。一级、二级问题在汉化前后向模型发送的选项文本保持一致；模型返回之后才将标签及概率键转换为中文。

这保证已有检查点与训练 JSONL 可以继续使用。不要直接重命名 `criteria` 的内部键，也不要调整选项顺序来替代展示层转换。修改中文名称时，在 `cn_names` 中维护映射，并同步本手册；加入新二级类还需要重新验证模型效果。

现有训练集只监督了 12 个一级正交维度，未包含 `topic_l2`。二级主题已接入推理，但没有独立人工评测，本次名称转换不构成新的模型效果验证。
