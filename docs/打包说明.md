# 分发包说明

打包脚本：`python scripts/package.py`（或 `bash scripts/package.sh`）

| 包 | 内容 | 大小量级 | 给谁 |
|---|---|---|---|
| `pbz-comment-insight-<v>-src.zip` | 代码 + 配置 + 体系 + 文档 + 测试 | ~100 KB | 看代码 / 二次开发 |
| `pbz-comment-insight-<v>-full.zip` | 上面 + 原始数据 + 中间产物 + 报告（**不含权重**） | ~30 MB | 复现流水线 |
| `laya-pbz-v1-weights.zip` | 微调权重（`model.safetensors` + tokenizer + config） | ~620 MB | 只想直接推理 |

## 收到 full 包怎么跑

```bash
pip install -e .
pbz info          # 确认产物状态
pbz aggregate     # 直接出报告（用包里自带的 pred_full.parquet）
```

要重跑推理需要权重包：解压到 `artifacts/ckpt/laya-pbz-v1/`，然后

```bash
pbz predict
pbz evaluate
```

## 只收到 src 包

需要自备数据（`data/raw/cache/*.json`，格式见 `src/pbz/rebuild.py::flatten_cache`），
然后端到端：

```bash
pbz pipeline      # 含约 1 小时微调
```

## 权重为什么单独打

`model.safetensors` 615 MB，和代码一起压会让 src 包无法走邮件/IM。
另外 `laya.train` 产出的 `checkpoint_latest/` 是最终权重的完整副本（又一个 615 MB），
`pbz train` 结束时会自动删掉它。
