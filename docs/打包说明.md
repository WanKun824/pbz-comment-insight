# 分发包说明

公开权重发布在 [GitHub Release v1.0.0](https://github.com/WanKun824/pbz-comment-insight/releases/tag/v1.0.0)。下载后的操作步骤见 [模型下载与调用](模型下载与调用.md)。

打包脚本：`python scripts/package.py`。可通过 `--only` 只生成需要的包：

| 包 | 内容 | 用途 |
|---|---|---|
| `pbz-comment-insight-<v>-src.zip` | 代码、配置、标签体系、文档、示例与测试 | 源码分发 |
| `pbz-comment-insight-<v>-full.zip` | 源码包加本地数据、中间产物、报告，不含权重 | 内部复现，含评论原文，不作为公开附件 |
| `laya-pbz-v1-weights.zip` | 固定检查点的完整运行文件、模型卡、许可和清单 | 公开模型分发，约 600 MB |

每个包生成同名 `.zip.sha256`，保存完整的 64 位 SHA-256。公开 Release 只上传权重 zip 与其校验文件；GitHub 另提供标签对应的源码下载。

## 生成权重包

默认写入项目的 `dist/`；空间不足时，可通过 `--out-dir` 指定其他磁盘：

```bash
python scripts/package.py --only weights
python scripts/package.py --only weights --out-dir D:/pbz-release
```

默认输出：

```text
dist/laya-pbz-v1-weights.zip
dist/laya-pbz-v1-weights.zip.sha256
```

权重包只从 `artifacts/ckpt/laya-pbz-v1/` 选取以下 8 个检查点文件：

- `model.safetensors`
- `encoder/config.json`
- `tokenizer/tokenizer.json`
- `tokenizer/tokenizer_config.json`
- `rl_agent_config.json`
- `questions.json`
- `train_summary.json`
- `train_report.json`

缺少任意必需文件时停止打包。其他检查点、`checkpoint_latest/` 快照、训练 JSONL 和评论数据不会进入权重包。

另外包含 `LICENSE`、`MODEL_CARD.md`、`模型下载与调用.md`、`两级中文标签.md` 与 `manifest.json`。清单记录源码提交、代码版本和每个文件的大小、SHA-256。所有文件都位于压缩包的 `laya-pbz-v1/` 根目录下。

`model.safetensors` 为 643,835,524 字节；完整检查点约 678 MB，压缩后约 600 MB。打包和校验使用分块读取，不将整个权重文件一次性读入内存。

## 校验与解压

将 zip 和同名 `.zip.sha256` 放在同一个目录，执行：

```bash
python scripts/package.py --verify dist/laya-pbz-v1-weights.zip
python -m zipfile -e dist/laya-pbz-v1-weights.zip artifacts/ckpt
```

校验会检查压缩包摘要、文件清单、重复或额外成员，以及每个成员的大小和摘要。解压后的权重路径应为 `artifacts/ckpt/laya-pbz-v1/model.safetensors`。

## 源码包与内部复现包

```bash
python scripts/package.py --only src
python scripts/package.py --only full
```

源码包没有评论数据和模型权重。使用它进行推理时，需要另外下载权重，并准备自己的评论输入；单条示例可直接通过命令行传入正文。

内部复现包的内容由本机现有产物决定，可能包含评论原文、用户标识和人工标注待办，保留在内部环境中使用。它不属于公开模型 Release 的附件。

## 发布验证

```bash
python -m pytest tests/ -q
python -m ruff check src tests scripts examples
python scripts/package.py --verify dist/laya-pbz-v1-weights.zip
```

完整包还需按操作文档运行真实推理示例。本次发布已在 CPU 和 GPU 上通过真实离线两级推理验证；权重未因打包而重新训练。
