# 下载模型并运行推理

训练好的检查点 `laya-pbz-v1` 通过 GitHub Release 发布。下载权重包并安装依赖后，可以直接分析自己的评论，无需重新训练，也无需下载本项目的原始评论数据。

- [v1.0.0 发布页](https://github.com/WanKun824/pbz-comment-insight/releases/tag/v1.0.0)
- [完整权重包：laya-pbz-v1-weights.zip](https://github.com/WanKun824/pbz-comment-insight/releases/download/v1.0.0/laya-pbz-v1-weights.zip)
- [完整 SHA-256：laya-pbz-v1-weights.zip.sha256](https://github.com/WanKun824/pbz-comment-insight/releases/download/v1.0.0/laya-pbz-v1-weights.zip.sha256)

压缩包约 **600 MB**，解压后约 **678 MB**；其中 `model.safetensors` 为 643,835,524 字节。包内包含 tokenizer、配置、模型卡、许可和逐文件校验清单。源码保存在普通 Git 仓库，权重保存在 Release 附件。

## 1. 获取源码

```bash
git clone https://github.com/WanKun824/pbz-comment-insight.git
cd pbz-comment-insight
git checkout v1.0.0
```

已经克隆过项目时，可以用 `git pull` 更新 `main`；要复现本次发布，则先 `git fetch --tags`，再切到 `v1.0.0`。

## 2. 下载、校验和解压权重

安装了 GitHub CLI 时：

```bash
gh release download v1.0.0 --repo WanKun824/pbz-comment-insight --pattern "laya-pbz-v1-weights.zip*" --dir dist
python scripts/package.py --verify dist/laya-pbz-v1-weights.zip
python -m zipfile -e dist/laya-pbz-v1-weights.zip artifacts/ckpt
```

没有 GitHub CLI 时，使用上面的浏览器直链下载 **zip 和 .sha256 两个文件**，保持文件名原样并放进项目的 `dist/` 目录，然后执行后两条命令。校验和解压只使用 Python 标准库，可在安装模型依赖之前运行。

校验脚本会检查整个 zip 的完整 SHA-256、目录结构，以及包内每个文件的大小和 SHA-256。校验成功后会输出 `[verified]`。

**解压目标是 `artifacts/ckpt`。** 压缩包已经包含 `laya-pbz-v1/` 这一层目录，最终结构应为：

```text
artifacts/ckpt/laya-pbz-v1/
├── model.safetensors
├── rl_agent_config.json
├── questions.json
├── encoder/
│   └── config.json
├── tokenizer/
│   ├── tokenizer.json
│   └── tokenizer_config.json
├── train_summary.json
├── train_report.json
├── LICENSE
├── MODEL_CARD.md
├── 模型下载与调用.md
├── 两级中文标签.md
└── manifest.json
```

不要多解压出一层 `laya-pbz-v1/laya-pbz-v1/`。若默认目录已有需要保留的自训练模型，可以解压到别处，并在调用时指定 `--ckpt <检查点目录>`。

## 3. 安装运行环境

建议 Python 3.11，使用独立虚拟环境。Windows PowerShell：

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e . "laya==0.4.21" "transformers==5.3.0"
```

Linux / macOS：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e . "laya==0.4.21" "transformers==5.3.0"
```

上述 Laya 与 transformers 版本用于本次实测。项目要求 Python ≥3.10、PyTorch ≥2.4、transformers ≥5.0；检查点使用 `parallel` 选项布局，走默认 eager 推理后端。

需要 NVIDIA GPU 时，安装与驱动匹配的 CUDA 版 PyTorch，可按 [PyTorch 安装说明](https://pytorch.org/get-started/locally/) 选择对应命令。检查环境：

```bash
python -c "import torch, laya, transformers; print('torch:', torch.__version__); print('transformers:', transformers.__version__); print('CUDA:', torch.cuda.is_available())"
pbz info
```

`pbz info` 中 `ckpt (weights)` 应为 `[x]`。刚克隆时 clean、weak、train、pred 可能为缺失状态，这些文件不是运行单条评论示例的前提。

## 4. 先分析一条评论

GPU：

```bash
python examples/predict_comment.py --device cuda --video "影之刃零游戏体验" --comment "着色器编译等待很久，进游戏后经常掉帧，希望后续能修复这些性能问题。"
```

CPU：

```bash
python examples/predict_comment.py --device cpu --video "影之刃零游戏体验" --comment "着色器编译等待很久，进游戏后经常掉帧，希望后续能修复这些性能问题。"
```

示例执行完整的两级推理，并将主题标签转换为中文。上述合成输入在本次 CPU 和 GPU 实测中均输出一级主题「技术性能」、二级主题「着色器编译」。其他输入应以实际返回结果为准，示例结果不代表模型准确率保证。

返回 JSON 中，每个维度含 `label` 和 `confidence`；一级、二级主题为中文。`valid` 为 `fragment` 或 `spam` 时，不执行二级推理，也不输出 `topic_l2`。示例过滤了未训练的 `is_sarcasm` 和 `is_actionable` 两个维度。

楼中楼可以补充上下文：

```bash
python examples/predict_comment.py --device cuda --video "手柄体验" --parent "你用的是什么手柄？" --comment "我用的索尼手柄，按键识别有问题，希望能修。"
```

支持的参数：`--comment`、`--video`、`--parent`、`--thread`、`--device`、`--ckpt`；运行 `python examples/predict_comment.py --help` 可查看说明。

## 5. 在 Python 项目中调用

在项目根目录运行以下代码。模型加载一次后，可以反复调用 `predict_comment`，无需为每条评论重新加载权重。

```python
from examples.predict_comment import predict_comment
from pbz.config import load_config
from pbz.schema import load_agent, load_schema

cfg = load_config()
schema = load_schema(cfg.path("paths.taxonomy"))
agent = load_agent(
    cfg.path("paths.ckpt"),
    device="cuda",  # 无 GPU 时改为 cpu
    max_len=768,
    head_max_len=320,
)

result = predict_comment(agent, schema, {
    "game": cfg.game,
    "video": "影之刃零游戏体验",
    "comment": "着色器编译等待很久，进游戏后经常掉帧。",
})

print(result["topic_l1"]["label"])
if "topic_l2" in result:
    print(result["topic_l2"]["label"])
print(result["topic_l1"]["probs"])
```

Python 返回值还包含 `p`（置信度）、`margin`（前两名概率差）、`probs`（选项概率）和 `n_rot`。两级主题的标签及概率字典键都是中文；其他维度遵循原有内部值约定。服务接入时可复用同一个 agent；大批量任务建议使用下一节的批处理入口。

## 6. 批量推理

已有清洗数据时：

```bash
pbz predict --device cuda --batch-size 1 --limit 10 --out artifacts/pred/smoke.parquet
pbz predict --device cuda --batch-size 1 --out artifacts/pred/pred_new.parquet
```

显存足够后再增大 `--batch-size`。无 GPU 时使用 `--device cpu`。

也可以准备自己的 CSV 或 parquet，至少包含字符串列 `state`，每个 state 是上述 `game/video/thread/parent/comment` 结构的 JSON 字符串：

```bash
pbz predict --states my_states.parquet --device cuda --batch-size 1 --out artifacts/pred/custom.parquet
```

输出字段包括 `p_topic_l1`、`p_topic_l2`、对应 `c_` 置信度列，以及 `probs_json`。碎片、垃圾评论或 `--no-pass2` 模式下，二级主题为空。

只有 `state` 的输入足够推理。运行 `pbz aggregate` 还需要 `rpid`、`时间`、`点赞`、`视频标题`、`内容` 等业务字段；完整输入可通过 `pbz rebuild` 生成，格式见 [数据目录说明](../data/README.md)。

```bash
pbz aggregate --pred artifacts/pred/pred_new.parquet
```

## 7. 常见问题

| 情况 | 处理方法 |
|---|---|
| `No module named laya` | 激活安装依赖的虚拟环境，确认 `python -m pip show laya` 可以找到包 |
| transformers 4.x 加载失败 | 按上面的版本安装命令升级到本次验证的 5.3.0 |
| `CUDA: False` | 使用 `--device cpu`，或安装与驱动匹配的 CUDA 版 PyTorch |
| GPU 显存不足 | 使用 `--batch-size 1`；单条示例也可改为 CPU |
| 检查点缺失或加载失败 | 核对目录层级、zip 校验结果及 tokenizer 文件是否齐全 |
| `clean` 或 `pred` 缺失 | 单条示例可直接运行；默认批处理和报告需要另行准备输入数据 |
| 解压后尝试下载基座 | 核对本地检查点路径及完整目录结构；本次完整包已通过离线加载验证 |
| PowerShell 阻止激活脚本 | 可直接用 `.\.venv\Scripts\python.exe` 运行 Python 命令，用 `.\.venv\Scripts\pbz.exe` 运行 pbz 命令 |

## 8. 模型效果边界

本次发布的是既有微调权重及配套调用工具，没有重新训练模型。测试标签来自规则弱监督，且历史划分存在少量重复；二级主题没有独立人工评测。`is_toxic`、中立情感等已知问题见 [模型卡](MODEL_CARD.md)，完整的 8+67 中文标签见 [两级中文标签](两级中文标签.md)。

完整权重包已通过 SHA-256 和逐文件校验；本次发布的调用步骤在本地 CPU 和 GPU 上均通过真实离线推理验证。Python 版本与硬件实测记录见 Release 发布说明。
